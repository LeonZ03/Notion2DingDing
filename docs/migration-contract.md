# 本地迁移契约

当前 Windows 本地链路只接受 Notion 官方 `HTML` 导出 ZIP 或解压目录，输出为钉钉在线文字文档。Markdown 导出会被明确拒绝。

## 一条命令迁移

```powershell
npm run migrate -- --input "D:\Downloads\Notion-HTML-Export.zip" --folder "目标文件夹 nodeId"
```

知识库目标改用 `--workspace "workspaceId"`。两种目标必须且只能选择一个。标题默认从根 HTML 页面读取，也可用 `--name` 修改；多个独立根页面无法唯一推断时，可用 `--entry "页面.html"` 指定。

子页面默认使用 `--subpages inline`，递归追加到同一文档。显式指定 `--subpages tree` 时，每个页面创建同名文件夹和同名独立钉钉文档。即使用户配置的是普通 `folderId`，树模式也会先只读解析该节点的真实归属：Workspace 节点使用 `workspaceId + folderId` 的 Wiki 创建接口，真正的钉盘节点才使用 Drive 创建接口。

命令依次完成依赖和登录预检、HTML/图片资源预检、自包含 DOCX 生成、多栏布局整理、钉钉导入、根页面原生封面、子页面目录/分栏/代码块/待办的恢复，以及真实 URL 回读。只有回读验证通过、且本地垃圾永久清理完成，才会返回 `success: true`。

## Edge 异步任务契约

Edge、Windows 界面和 CLI 继续进入同一个迁移核心。Edge 不直接运行第二套转换逻辑，而是通过一个持续的 Native Messaging 连接调用：

- `migration.inspect`：只解包并读取 ZIP 内根页面标题、根 HTML 导出时间和页面数量，并按源 SHA-256 与当前目标查询不含正文的最小迁移记录；响应前永久删除 Native Host 预检副本，不生成 DOCX、不调用 dws，也不创建迁移任务；
- `migration.start`：校验并暂存单个 HTML ZIP，返回 16 位随机 Native 任务 ID；
- `migration.status`：返回 `queued/running/cancel_requested/succeeded/failed/unknown/cancelled`、五阶段进度、可取消状态和最终结果；
- `migration.cancel`：只在预检或本地转换阶段终止进程并永久清理暂存数据；
- 进入钉钉写入阶段后 `canCancel=false`，因为强制终止可能留下无法确认的远端文档；
- 写入未知时返回 `unknown + recover`，保留真实文档 URL（如已取得）；不做自动重试，但允许用户明确选择创建一份新文档；
- 确定失败按 `login/target/select_export/retry/recover` 给出可操作恢复类型。

弹窗选择 ZIP 后先调用 `migration.inspect`，以包内根页面标题覆盖默认标题并显示导出时间和页面数量；用户仍可修改标题。若相同内容曾迁移到当前目标，预检返回最新一条已确认成功记录（没有成功记录时返回最新未知记录）、真实钉钉 URL、时间、模式和去重后的文档记录数。弹窗必须显示“此前已导出/此前可能已导出”和可点击链接，主按钮相应变为“仍再次导出/再次导出为新文档”；只有用户明确点击后才以 `createNew=true` 调用 `migration.start`。为避免较大导出包关闭 Edge 的一次性扩展消息通道，弹窗以 512 KiB Base64 分片发送，后台核对分片数量和总长度后才交给 Native Host；预检和正式转换是两次独立传输，预检不会创建任务或写入钉钉。扩展入口限制原始 ZIP 不超过 46 MiB，更大输入继续使用 Windows 一键工具。弹窗只把 Native 任务 ID 和来源 Notion 页面身份保存到 `chrome.storage.session`，用于同一 Edge 会话、同一个 Notion 页面内关闭再打开后的状态恢复；切换到其他 Notion 页面时不显示旧任务结果或旧文档链接。页面身份只取稳定页面 ID，不保存查询参数、标题、正文或导出内容；导出包字节仅保留在当前弹窗和扩展后台内存中，图片、凭据和目标内部 ID 都不进入扩展存储。

## 内容映射

| Notion HTML 内容 | 钉钉文档映射 |
| --- | --- |
| 根页面标题 | 只用作钉钉文档标题；不再作为 Pandoc `Title` 或正文一级标题重复写入 |
| 根页面封面 | 不进入 DOCX 正文；导入后上传为钉钉原生文档封面并回读样式确认 |
| 标题、段落、粗体、斜体 | 可编辑富文本 |
| 有序、无序和嵌套列表 | 对应列表；极深层级以钉钉最终支持为准 |
| 普通表格 | 可编辑表格 |
| 代码块 | 导入后原位恢复为钉钉原生代码块；保留换行、缩进和 HTML 导出中可识别的语言 |
| 本地链接 | `inline` 模式把子页面入口合并为原生目录；`tree` 模式回填为独立钉钉文档 URL |
| 普通单图 | 直接写为 DOCX 图片段落，不使用 1×1 Figure 表；再由钉钉转存为其托管资源 |
| 子页面 | 默认追加到同一篇文档；树模式按“同名文件夹 → 同名文档”递归创建并保留跨文档跳转 |
| 单列容器 | 直接输出列内内容，不生成 1×1 布局表 |
| 两列及以上多栏 | DOCX 无边框布局表先保留同行关系；导入后恢复为钉钉原生 `sr:true` 分栏，外围不按普通表格显示 |
| 三图并排 | 三张图片位于同一布局行 |
| 图片 + 表格同排 | 图片与数据表位于同一布局行的不同列 |
| Callout | 保留文本内容；装饰样式可能简化 |
| Toggle | 保留展开内容，不保留折叠交互 |
| 数据库 CSV | 记录明确降级警告；数据库视图和交互不迁移 |
| 普通附件 | 保留链接，暂不自动上传附件内容 |
| Notion 书签卡片 | 保留链接和文字；未随导出包提供的外部站点图标/缩略图明确省略，不联网抓取 |

正文和 Figure 中的远程图片 URL 不属于可靠链路，预检会拒绝。书签卡片内的外部预览图片属于装饰资源，会以 `BOOKMARK_EXTERNAL_PREVIEW_OMITTED` 警告明确省略；书签链接和文字继续迁移。请保留 Notion HTML 导出包中随页面下载的本地内容图片。

## 可靠性约束

- 页面、子页面、CSV、图片和 DOCX 都计算 SHA-256；缺失、越界、损坏或非 HTML 输入不会调用钉钉写接口。
- 图片总体积可能触发钉钉 DOCX 上限时，转换器只在工具临时目录中把较大的 PNG 以高质量 JPEG 重新编码；源 ZIP/目录不变，并同时记录源文件与本地化文件的大小和 SHA-256。
- 最终 DOCX 仍超过 20 MiB 时返回 `IMPORT_FILE_TOO_LARGE`，在调用 dws 前停止，避免把确定的大小错误误报成写入状态未知。
- 图片报告记录源引用数、本地文件数、去重资源数、DOCX 媒体数和实际图片出现次数。
- 根页面封面单独记录文件大小和 SHA-256，只暂存在工具任务目录；原生封面设置前后读取文档样式，写入回执未知但样式已确认时按成功处理，样式无法确认时保留原文档 URL 并禁止重复导入。
- 书签报告单独记录书签数和被省略的外部预览图片数；这些装饰图片不计入源内容图片数，也不会削弱正文外部图片的失败检查。
- 子页面报告记录目标页面与全部入口的源页面、可见文字、目标序号和标题；导入后按标题、数量与顺序精确定位真实 H2 UUID，再生成一个只含这些子页面的原生 `toc`。回读必须确认目录项数量、文字、顺序和 `anchorId` 全部一致，且旧入口块已删除；目录更新或删除状态未知时只回读恢复，不重复导入。
- 树模式先生成页面关系清单，再创建全部容器文件夹、逐页转换导入，最后二次回填跨文档 URL。物理归属采用首次遍历得到的父页面；重复引用保留为链接，循环引用不会无限递归。
- 树模式逐页保存不含标题、正文、文件名和输入路径的最小状态。文件夹创建回执未知时禁止重试；部分页面已成功时复跑只复用既有文件夹和文档，再继续未完成页面或链接回读。
- 列布局报告分别记录单列容器、多列容器、源列总数，以及 DOCX 中全部布局表/真实数据表的顺序和列数；导入后只选取保留 `Notion Columns` 专用样式的表格，并核对其数量和列数，再恢复为钉钉原生 `sr:true` 分栏。普通数据表不参与更新；专用样式或列数无法对账时停止修改。
- 代码块会核对 Notion HTML、DOCX `SourceCode` 段落和钉钉块的数量及正文；导入后只把匹配的段落原位更新为官方 JSONML `code` 块，并回读确认块类型、正文和语言。
- 分栏恢复会把 Word 导入遗留且不符合钉钉 JSONML schema 的 `list.start<1` 最小化纠正为 `1`，删除外层布局表及其直接单元格的边框属性，设置 `sr:true` 后回读核对；更新结果未知时只在已有文档继续恢复，不重复导入。
- 根页面标题在 DOCX 中执行结构审计：`Title` 样式段落必须为 0，与根标题同名的 `Heading1` 必须为 0；子页面标题和正文中的其他标题继续保留。
- 相同输入、标题、目标、profile 和转换算法版本使用稳定任务 ID；已有成功记录默认复用，避免重复文档。修正会改变文档结构时提升算法版本，防止错误复用旧文档。
- 导入写入本身未知时状态为 `unknown` 并禁止自动重试；默认 CLI 仍可在已有文档恢复原生块和回读。用户显式传入 `--force` 或 Edge 发送 `createNew=true` 时，允许忽略旧的成功/未知远端状态并新建文档，但清理失败仍不可绕过。
- 回读图片数量只统计非 `data:` 的远端图片，钉钉为清单等内容生成的内联 SVG 只记录为忽略数量；实际图片数仍不得少于源引用数。
- 目标文件夹已有同名文档时，严格接受钉钉追加的数字后缀并设置 `titleAdjusted: true`，不能把标题调整误报为写入失败。
- 中间 HTML 副本、图片副本、DOCX 和临时日志只存在于工具专属任务目录；成功、失败和未知状态都会永久删除并验证路径不存在，不经过回收站。
- 清理失败返回 `CLEANUP_FAILED`，不能伪装成功。
- 最小幂等状态不得包含正文、图片、原文件名、输入路径或 DOCX 路径。
- 用户提供的源 ZIP 或目录始终保留，不会被工具自动删除。

## 主要错误码

| 错误码 | 含义与处理 |
| --- | --- |
| `HTML_INPUT_INVALID` | 不是可识别的 Notion HTML 导出；重新按 HTML 格式导出 |
| `DWS_NOT_AUTHENTICATED` | 未登录或 Token 失效；先运行 `dws auth login` |
| `CONVERSION_FAILED` | ZIP、HTML、图片或布局结构有问题；修复输入后重试 |
| `IMAGE_AUDIT_MISMATCH` | 源图片、本地化结果或 DOCX 输出数量不一致；不会写入钉钉 |
| `COVER_CONVERSION_AUDIT_INVALID` / `COVER_NATIVE_RESTORE_FAILED` | 封面暂存映射无法核对，或钉钉原生封面设置后无法从文档样式回读确认；保留已有文档 URL，不重复导入 |
| `CODE_READBACK_MISMATCH` / `CODE_NATIVE_VERIFY_FAILED` | DOCX 导入后的代码段落与源 HTML 不一致，或原生代码块更新后回读不一致；保留文档 URL且不重复导入 |
| `SUBPAGE_READBACK_MISMATCH` / `SUBPAGE_TOC_VERIFY_FAILED` | 子页面入口、追加 H2 或原生目录项无法精确对账；停止修改并保留文档 URL，相同任务只恢复原文档而不重复导入 |
| `TREE_FOLDER_CREATE_UNKNOWN` | 递归文件夹没有返回可确认 ID；禁止直接重试，避免重复目录 |
| `TREE_LINK_READBACK_MISMATCH` / `TREE_LINK_VERIFY_FAILED` | 树模式的原入口无法安全定位，或跨文档 URL 更新后回读不一致；保留已创建文档并在相同任务上恢复 |
| `LAYOUT_READBACK_MISMATCH` / `LAYOUT_NATIVE_VERIFY_FAILED` | 钉钉中的 `Notion Columns` 专用样式、分栏数量或列数与 DOCX 审计不一致，或原生分栏回读失败；停止修改以保护普通数据表，并保留文档 URL |
| `IMPORT_FILE_TOO_LARGE` | 自动优化后 DOCX 仍超过钉钉 20 MiB 导入上限；减少图片体积或拆分页面后重试 |
| `IMPORT_PERMISSION_DENIED` | 当前账号对目标目录或知识库无写权限 |
| `IMPORT_COMMIT_UNKNOWN` | 写入结果未知；先人工确认，不能直接重试 |
| `READBACK_FAILED` / `READBACK_MISMATCH` | 服务端可能已创建文档，但正文或图片验证未通过；相同任务再次执行只恢复回读，不重复导入 |
| `CLEANUP_FAILED` | 中间数据未能永久删除；按返回路径处理后再继续 |

## 图片与布局验收

迁移成功时会回读图片数量，并确认目标图片不依赖 Notion 临时 URL。普通单图必须通过 DOCX 审计确认不在任何表格中；多栏还必须确认图片没有嵌套 1×1 Figure 表，并通过布局行、列宽与实际渲染检查。最终在真实钉钉文档中人工核对单图无框、“三图同排”和“图片/表格同排”。
