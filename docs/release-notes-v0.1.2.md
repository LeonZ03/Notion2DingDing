# Notion2DingDing v0.1.2

本次完善 Windows 本地助手的卸载体验，迁移流程保持不变。

- Windows“已安装的应用”和开始菜单提供卸载入口，安装器无需保留。
- 移除 Edge 扩展后打开本地助手卸载说明页，引导用户完成本地清理。
- 清理本项目安装并标记的专属 Node.js、Pandoc、dws 和对应 PATH 条目，保留共享依赖。
- 默认保留钉钉 DWS 登录状态；用户可在确认窗口明确选择清除本机全部 DWS 账号，这会影响其他 DWS 用途。
- 用户提供的 Notion 导出包和已生成的钉钉文档始终保留。

已有用户需要运行一次新版安装器完成升级，才会获得 Windows 卸载入口。旧版即使没有入口，也可直接使用新版安装器的 `-Action Uninstall` 参数卸载，无需先安装。Edge 只能打开卸载引导页，不能自动删除 Windows 本地程序。

安装器继续使用项目下载站和 SHA-256 校验，当前仍未进行 Authenticode 签名。
